🎮 BibliotecaGamer

Proyecto grupal desarrollado para la asignatura de Desarrollo de Interfaces.

BibliotecaGamer es una aplicación de escritorio desarrollada con Java y JavaFX 
que permite gestionar una biblioteca de videojuegos mediante una interfaz gráfica intuitiva.

🚀 Tecnologías utilizadas

- Java
- JavaFX
- Git
- GitHub
- CSS
  
📋 Funcionalidades

- Gestión de videojuegos
- Navegación mediante interfaz gráfica
- Visualización de información de los juegos
- Organización mediante modelo y controlador
- Integración de diferentes componentes JavaFX
  
👥 Trabajo en equipo
Proyecto realizado en colaboración con otros compañeros como parte de una práctica académica de Desarrollo de Interfaces.

🎓 Contexto académico
Proyecto desarrollado durante el ciclo de Desarrollo de Aplicaciones Multiplataforma (DAM).
